# FinansSys - Sistema de Checkout E-commerce para comprar com cartão de crédito

O **FinansSys** é uma solução de checkout intuitiva e segura desenvolvida para e-commerces, visando otimizar a experiência de compra do usuário e prevenir transações fraudulentas através de validação em tempo real ao comprar.

---

## Problema a aplicação resolve

Em fluxos de checkout convencionais, falhas de validação de dados do cartão de crédito e a falta de feedback claro durante o processamento de compras causam alta taxa de abandono de carrinho ou perdas com transações fraudulentas. 

O FinansSys resolve esse problema ao:
- Validar formulários em tempo real com regras estritas de preenchimento.
- Aplicar verificação automática de padrões suspeitos no cartão (regra antifraude de dígitos idênticos).
- Garantir roteamento fluído e intuitivo por todo o ciclo da compra (carrinho, pagamento, confirmação e tratamento de erros).

---

## Tecnologias e Técnicas Utilizadas

* **React (Vite):** Biblioteca para construção da interface reativa e performática.
* **React Router Dom:** Gerenciamento de rotas e navegação entre telas no modelo SPA.
* **React Hook Form:** Gerenciamento eficiente e performático de formulários.
* **Zod:** Validação e tipagem de esquemas de dados de entrada.
* **Custom Hooks (`usePagamento`):** Isolamento de regras de negócio assíncronas e gerenciamento de estado global da transação.
* **Git Flow:** Estrutura estrita de branches (`main`, `develop` e `feature/*`) mantendo commits no padrão imperativo.
* **Trello Kanban:** Usado para fazer o planejamento do projeto.
